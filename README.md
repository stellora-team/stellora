# ✨ Stellora

**Stellora** is a personal productivity and self-development platform that brings everyday planning, habit tracking, focus sessions, notes, mood tracking, and memories together in one digital space.

The project's distinctive feature is **Personal Cosmos**: a visual representation of personal progress. As users complete habits, tasks, goals, and focus sessions, they contribute to the development of themed constellations representing different areas of their lives.

> **Project status:** Planning and development. Features described below are planned and are not necessarily implemented yet.

## 🎯 Project Goal
Create a unified digital environment that helps users organize their daily activities, build positive habits, track their achievements, and stay motivated through a visual progress system.

## 🌟 Planned Features
1. **Registration and authentication** — account creation, sign-in, sign-out, and basic profile management.
2. **Habit management** — create, edit, delete, mark completion, and review habit progress.
3. **Goals and tasks** — manage personal goals and tasks, set deadlines, and track progress.
4. **Focus sessions** — run a focus timer linked to a selected task or goal and record session duration.
5. **Statistics and progress tracking** — view activity statistics for habits, goals, tasks, and focus sessions.
6. **Mood tracking** — record moods with dates and times.
7. **Notes and calendar** — create, edit, and delete personal notes.
8. **Memory journal** — save important events with descriptions, dates, and locations.
9. **Personal Cosmos** — visualize life areas as constellations that evolve with completed activities.
10. **Reminders and notifications** — configure reminders for habits, tasks, goals, and scheduled activities.

## 🏗️ Repository Structure

This project uses a **monorepo** to keep its web, server, and mobile components together.

```text
stellora/
├── frontend/          # Web application
│   └── .gitkeep
├── backend/           # Server-side application and API
│   └── .gitkeep
├── mobile/            # Mobile application
│   └── .gitkeep
└── README.md          # Project overview
```

The `.gitkeep` files are placeholders used to preserve the directory structure until development files are added.
